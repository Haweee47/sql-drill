# SQL 드릴

데이터 분석 채용 전형의 **SQL 쿼리 테스트**를 실제와 같은 조건으로 연습하는 사이트입니다.
브라우저에서 바로 돌아갑니다. 서버도, 회원가입도, 설치도 없습니다.

**→ https://haweee47.github.io/sql-drill/**

---

## 왜 만들었나

쿼리 테스트를 준비하면서 기존 연습 사이트들이 실제 시험과 다른 점을 발견했습니다.

| | 보통의 연습 사이트 | 실제 쿼리 테스트 |
|---|---|---|
| 채점 | 데이터 한 벌 | **여러 데이터셋을 전부 통과**해야 함 |
| 정수 나눗셈 | 보통 실수로 처리 | `*1.0` 이 없으면 **0** 이 나옴 |
| 컬럼 | 이름이 달라도 통과 | 이름·순서·정렬까지 정확히 일치 |
| 반올림 | 느슨 | 소수점 자릿수까지 채점 |

본 데이터로는 통과하는데 논리에 빈틈이 있는 답을 걸러내지 못하면 연습이 되지 않습니다.
그래서 **경계값·동점·끊김복귀·데이터없음·빈테이블·NULL섞임** 6개의 엣지 데이터셋을 따로 만들어
전부 통과해야 정답으로 처리합니다.

## 담긴 것

- **23문항** — 퍼널, 코호트 리텐션, 매출 분해, 윈도우 함수, 이동평균, 골든크로스,
  gaps and islands, 중앙값, A/B 집계, NULL·타입 처리
- **11개 테이블** — 문항마다 필요한 테이블만 보여줍니다
- **문항별 해설** — 같은 내용을 `쉬운 설명`과 `자세한 설명` 두 버전으로 썼습니다.
  상단에서 전환하거나 나란히 비교할 수 있습니다
- **함수 레퍼런스 13개** — `OVER()` 계열, 프레임, NULL 함수, gaps and islands 등

## 어떻게 돌아가나

```
브라우저
 ├─ sql.js (SQLite WASM)  ← 쿼리를 여기서 실행
 ├─ practice.sqlite       ← 2.8MB, 한 번 받아서 캐시
 ├─ expected.json         ← 정답은 미리 계산해 둔 값
 └─ datasets.json         ← 엣지 데이터셋은 임시 DB 를 그때그때 만들어 비교
```

서버가 없습니다. 쿼리는 전부 **내 브라우저 안에서** 돌고 밖으로 나가지 않습니다.

실행 엔진이 SQLite 인 것은 의도입니다. 테스트돔에서 MySQL 문법을 골라도 `*1.0` 이 없으면
0 이 나왔는데, 그건 채점 엔진이 정수 나눗셈을 한다는 뜻입니다.
**문법은 MySQL, 셈은 정수 나눗셈** 조합이 실제 시험에 가장 가깝습니다.
MySQL 전용 함수(`DATE_FORMAT`, `DATEDIFF`, `TIMESTAMPDIFF`, `INTERVAL` …)는
[`sqlmy.js`](sqlmy.js) 에서 자바스크립트로 구현하거나 문법을 치환해 처리합니다.

## 직접 고쳐 쓰려면

문제·데이터·해설은 전부 [`src/`](src/) 의 파이썬 파일에서 생성됩니다.

```bash
cd src
python seed.py          # 연습용 데이터 생성 (DuckDB)
python make_sqlite.py   # SQLite 로 복제
python gen_examples.py  # 문항별 예시 입력/출력 생성
python regress.py       # 모범답안 21개 × 데이터셋 7개 회귀 테스트
python export_web.py    # 정적 사이트용 JSON + DB 내보내기
```

`regress.py` 는 꼭 돌리세요. 데이터셋이나 참조 정답을 건드린 뒤
다른 문항이 조용히 깨지는 것을 잡아 주는 유일한 장치입니다.

브라우저판이 서버판과 같은 채점 결과를 내는지는 `node src/test_web.js` 로 확인합니다.
